# CrooLyyTimer

**Twój czas między stronami.**

Nazwa aplikacji: **CrooLyyTimer**. Repozytorium: **croolyytimer**.
Pakiet Android: `pl.croolyy.timer`.

Marka pozostaje CrooLyyTimer, a nazwa funkcji po polsku to **stoper**: czas rośnie od zera.
Nie nazywamy jej minutnikiem i nie sugerujemy odliczania. Repo i pakiet zachowują ciągłość aktualizacji.

CrooLyyTimer to spokojny towarzysz codziennego czytania. Marka opiera się na ciepłym papierze,
leśnej zieleni i odrobinie złota. Komunikaty są krótkie, przyjazne i całkowicie po polsku.

| Element | Wartość |
| --- | --- |
| Leśna zieleń | `#244D3E` |
| Papier | `#F7F4EB` |
| Złoty akcent | `#B28C48` |
| Ciemne tło | `#141D18` |
| Ciemny tekst | `#232D27` |
| Nagłówki | systemowy krój szeryfowy |
| Interfejs | systemowy sans serif |
| Pomiar czasu | systemowy monospace |

Ikona adaptacyjna łączy otwartą książkę i zegar. Jest autorskim rysunkiem wektorowym,
nie wymaga pobierania grafik ani czcionek. Zastępcze okładki powstają lokalnie i mają
stały kolor wyprowadzony z identyfikatora książki. Zaokrąglone karty, cienkie linie
i duże cyfry są wspólne dla jasnego oraz ciemnego motywu.

Źródło znaku: `app/src/main/res/drawable/ic_brand.xml`. Wersja do dokumentów: `brand.svg`.
